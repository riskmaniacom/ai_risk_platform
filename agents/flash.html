SA / F-IRB / A-IRB 독립 3-Layer 앙상블
ℹ️각 방법론(SA/F-IRB/A-IRB)은 독립적인 3-Layer 앙상블 모델을 사용하며, 경과율 α에 따라 실측·모델·거시 가중치가 자동 조정됩니다.
Layer ① 실측 외삽층
일별 BS금액 × 전월 RC → 즉시 RWA 갱신.
미입수 세그먼트는 전기 동일 경과일 패턴으로 외삽.
가중치 공식w_obs = min(0.95, 0.35+0.97×α²)
경과율 61.9% (현재)w_obs ≈ 0.72
경과율 0% (월초)w_obs ≈ 0.35
경과율 100% (월말)w_obs = 0.95
Layer ② 시계열 앙상블층
ARIMA(35%) + XGBoost(40%) + LSTM(25%) 가중 평균.
Walk-Forward Cross Validation 5 Folds로 학습·검증.
가중치 공식w_model = (1−w_obs)×0.69
ARIMA 내부 비중35%
XGBoost 내부 비중40%
LSTM 내부 비중25%

기준금리·환율·신용스프레드·연체율·신규여신 MTD
5개 실시간 신호변수로 보정항 산출.
