활용 AI 기법 상세 — 9가지
PSI / CSIM1
Population Stability Index로 학습 시점 대비 현재 변수 분포 변화를 정량화합니다. CSI는 개별 속성 bin 수준으로 분해하여 이탈 위치를 추적합니다.
PSI = Σ(Actual% − Exp%) × ln(Actual%/Exp%)
임계치: <0.05 정상 | 0.05~0.10 주의 | >0.10 이상
마할라노비스 거리M1
변수 간 공분산 구조를 고려한 다변량 거리 기반 이상치 탐지. 차주구분·상품코드·담보유형 등 복수 속성 조합의 논리적 정합성을 동시에 검증합니다.
D² = (x−μ)ᵀ Σ⁻¹ (x−μ)
확정 임계치: D² > 3.5 (신뢰수준 97.5%)
동적 임계치 ±2σM1·2·3
고정 임계치 대신 12개월 이동평균 ± 2 표준편차를 실시간 계산. STL 계절성 분해 후 잔차가 임계치를 초과하면 Critical로 자동 상향 분류합니다.
Upper = μ₁₂ + 2σ₁₂
STL 잔차 이탈 시 → Critical 상향
자산분류 전이 행렬M2
전월(T-1) 대비 당월(T) 자산분류 변동을 n×n 행렬로 시각화합니다. 대각선=정상 유지, 비대각선 고값=비논리적 전이로 판단하여 즉시 경보를 발령합니다.
비대각 고값 → 이상 전이 의심
금월 탐지: 일반기업→소매 86건
클러스터링M2·3
비지도학습 기반으로 이상 변동 건의 사유 패턴을 자동 그룹화합니다. 유형A(데이터결측)·B(로직부재)·C(리스크증가)로 수렴하여 보정 우선순위를 자동 도출합니다.
유형A 62건(즉시 보정) · 유형B 31건(개발) · 유형C 34건(정상)
XAI 원인 역추적M2
이상 탐지에서 그치지 않고 오류 발생 경로를 자연어로 설명합니다. SHAP 개념의 기여 변수 분해와 의사결정 트리 기반 룰 추출을 병행하여 조치 가이드를 생성합니다.
예: ㈜OO건설 → 동일인 인식 실패 → RW 50%→150% → +342억
무등급 원인 분류M3
의사결정 트리 기반 룰로 무등급 전이 경로를 자동 판별합니다. 데이터 결측에 의한 오분류와 실제 신용도 저하를 구분하여 불필요한 보정 작업을 최소화합니다.
매출액 결측 → 무등급 → RW 150%
보정 시: RWA 1,125억 감축 가능
자본차감 패턴 감지M3
자본차감 계좌 증가 사유를 적격등급 만료·담보 미갱신 등으로 자동 분류하고, 만료 예정 계좌의 사전 경보를 생성하여 사후 대응을 사전 예방으로 전환합니다.
금월: 적격등급 만료 11건 · 담보 미갱신 4건
