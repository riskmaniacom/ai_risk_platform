A AI(LLM) API 연결 설정 및 연동 테스트 API ENDPOINT 직접 설정

운용사·상품마다 PDF 양식(레이아웃, 표 구조, 용어)이 모두 다르기 때문에, 규칙/좌표 기반 방식으로는 모든 문서를 처리할 수 없습니다. AI(LLM) API를 이용해 PDF 텍스트 전체를 읽고, 펀드 기본정보와 기초자산(구성종목) 목록을 문서 양식에 관계없이 인식합니다. API 키/엔드포인트는 이 브라우저에만 저장되며(키는 저장하지 않음) 설정된 API 호출 외 다른 용도로 전송되지 않습니다.
🔗 현재 사용 중인 API Endpoint: (입력되지 않음)
ℹ️ 사용 순서(중요): ① API Endpoint URL을 직접 입력(아래 입력창) → ② API Key를 직접 입력(기본값 없음, 매번 입력 필요) → ③ 모델명 확인/입력 → ④ [🔌 연결 테스트] 버튼으로 정상 통신 여부 확인 → ⑤ 연결 성공 시에만 PDF 업로드/AI 인식 기능이 활성화됩니다.
미연결 (테스트 필요)
아직 연결 테스트를 실행하지 않았습니다. API 엔드포인트와 키를 입력한 뒤 [🔌 연결 테스트 실행] 버튼을 눌러주세요.
🧪 여러 모델 / 인증방식 한번에 진단하기 (모델 고정 문제인지 확인)
현재 입력된 API Endpoint와 API Key는 그대로 사용하고, 아래 체크된 모델명 × 인증방식 조합을 순서대로 모두 호출해봅니다.

3. 기초자산 유형별 코드 매핑 관리 TYPE → CODE MAPPING

    

      사용자가 정의한 기초자산 유형명(예: 상장주식)과 코드값(예: 10)을 미리 매핑해두면,
      AI 또는 규칙 기반 인식으로 파악된 자산유형이 이 목록과 자동 매칭되어 '기초자산유형' 컬럼에 코드값이 채워집니다.
      매핑은 직접 입력하거나 엑셀 파일(.xlsx/.xls)을 업로드하여 일괄 등록할 수 있습니다.
    


    

      ① 유형-코드 매핑 등록(직접입력/엑셀업로드)→
      ② 컬럼 역할 지정→
      ③ AI/규칙 기반 자동 추출→
      ④ 데이터 테이블 자동 입력
